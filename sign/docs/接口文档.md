# 接口文档（API v1）

> 基础地址：`http://<host>:8080`。所有接口返回 JSON；上传图片走 `dataURL` 字符串，不涉及 multipart。

---

## 1. 通用约定

### 1.1 响应结构

成功：

```json
{ "ok": true, "data": { } }
```

失败：

```json
{
  "ok": false,
  "error": {
    "code": "TEXT_REJECTED",
    "message": "内容包含不合规词语，请修改后再提交",
    "detail": { "hits": ["加微信"] }
  }
}
```

- `Content-Type: application/json; charset=utf-8`
- 所有时间均为 ISO 8601 字符串（服务器本地时区偏移），例如 `2026-10-23T17:56:12.345+08:00`
- 字段命名使用 camelCase

### 1.2 鉴权

| 场景 | 方式 |
| --- | --- |
| 公开接口 | 无需鉴权 |
| 后台接口 | 登录后由服务端下发 `sw_session` Cookie（HttpOnly、SameSite=Lax、12 小时有效） |
| 后台写操作 | 额外要求请求头 `X-Requested-With: signature-wall-admin`（CSRF 防护） |

登录失败过多会触发限流（见 1.4）。

### 1.3 大小限制

| 项目 | 限制 |
| --- | --- |
| 请求体 | 12 MB |
| 签名 PNG | 2 MB，必须为带透明通道的 PNG |
| 留影图片 | 4 MB，JPEG / PNG / WebP |
| 昵称 | 16 字符（后台可调 2–32） |
| 留言 | 80 字符（后台可调 10–200） |

### 1.4 限流

| 接口 | 限制 | 超限响应 |
| --- | --- | --- |
| `POST /api/signatures` | 90 次 / 分钟 / IP | `429 RATE_LIMITED`，带 `Retry-After` |
| `POST /api/admin/login` | 8 次 / 5 分钟 / IP | `429 RATE_LIMITED` |
| 后台其他接口 | 240 次 / 分钟 / IP | `429 RATE_LIMITED` |

### 1.5 媒体文件

签名与留影保存在 `/media/<id>-signature.png`、`/media/<id>-photo.jpg`，响应头 `Cache-Control: public, max-age=31536000, immutable`。

## 2. 公开接口

### 2.1 健康检查

`GET /healthz`

```json
{
  "ok": true,
  "uptime": 3612,
  "clients": 2,
  "signatures": 128,
  "memoryMB": 58
}
```

### 2.2 获取活动配置

`GET /api/config`

```json
{
  "ok": true,
  "data": {
    "event": {
      "title": "山水留痕",
      "subtitle": "落笔成景 · 把此刻留在山水之间",
      "org": "云栖山风景区",
      "venue": "游客中心 · 主入口",
      "date": "2026-10-23"
    },
    "theme": { "preset": "ink", "accent": "#e0b45c", "ink": "#0f2438", "paper": "#f6f1e6" },
    "wall": {
      "mode": "globe",
      "maxItems": 72,
      "showQr": true,
      "showTicker": true,
      "standbySeconds": 45,
      "sound": true,
      "photoWall": true
    },
    "kiosk": { "camera": false, "print": true, "allowMessage": true },
    "moderation": { "autoApprove": true, "action": "mask", "maxName": 16, "maxMessage": 80 },
    "mobileUrl": "http://192.168.1.20:8080/mobile",
    "publicBaseUrl": "http://192.168.1.20:8080",
    "serverTime": 1792740000000,
    "stats": { "total": 128, "today": 96, "approved": 128, "pending": 0, "photos": 12, "messages": 64, "words": 41 }
  }
}
```

`mobileUrl` 为二维码 / 海报使用的手机签名地址：优先取后台配置；其次读取 `X-Forwarded-Host` / `Host` 与 `X-Forwarded-Proto`（反向代理、域名、公网隧道部署时自动使用外部 HTTPS 地址）；若大屏是用 `localhost` 或虚拟网卡地址打开的，则自动换成评分最高的物理网卡地址（见 3.12）。

`publicBaseUrl` 为同一地址去掉 `/mobile` 后的站点根地址，供后台「其他设备访问」二维码使用（`${publicBaseUrl}/admin`）。

### 2.3 获取签名墙快照

`GET /api/wall?limit=72`

```json
{
  "ok": true,
  "data": {
    "items": [ { "id": "sig_...", "name": "林见山", "message": "山水有相逢", "...": "见 5.1" } ],
    "stats": { "total": 128, "today": 96, "approved": 128, "pending": 0, "photos": 12, "messages": 64, "words": 41 },
    "config": { "wall": { }, "theme": { }, "event": { } },
    "serverTime": 1792740000000
  }
}
```

仅返回 `status = approved` 的签名，按时间倒序，最多 `limit` 条（上限 200）。

### 2.4 获取单条签名

`GET /api/signatures/:id`

- `200`：返回签名对象（见 5.1）
- `404 NOT_FOUND`：不存在或已隐藏

### 2.5 提交签名

`POST /api/signatures`

请求体：

```json
{
  "name": "林见山",
  "message": "山水有相逢",
  "signature": "data:image/png;base64,iVBORw0KGgo...",
  "photo": "data:image/jpeg;base64,/9j/4AAQ...",
  "source": "mobile",
  "clientToken": "mob_1792740000_ab12cd34"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `signature` | 是 | 透明 PNG dataURL |
| `name` | 否 | 缺省"山水过客"；命中敏感词按策略打码或拒收 |
| `message` | 否 | 同上；后台关闭"允许留言"时忽略 |
| `photo` | 否 | 留影 dataURL，保存失败会降级为无照片，不影响签名 |
| `source` | 否 | `kiosk`（默认）/ `mobile`，用于卡片角标与后台筛选 |
| `clientToken` | 否 | 幂等令牌，10 分钟内重复提交返回首次结果（`duplicate: true`），避免弱网重试重复上墙 |

响应 `201`：

```json
{
  "ok": true,
  "data": {
    "id": "sig_mvkspnju_02ee2d8e",
    "name": "林见山",
    "message": "山水有相逢",
    "signatureUrl": "/media/sig_mvkspnju_02ee2d8e-signature.png",
    "signatureSize": { "width": 812, "height": 260, "bytes": 38210 },
    "photoUrl": null,
    "photoSize": null,
    "createdAt": "2026-10-23T17:56:12.345+08:00",
    "dateKey": "2026-10-23",
    "source": "mobile",
    "status": "approved",
    "moderation": { "masked": false }
  }
}
```

- 自动通过关闭时 `status` 为 `pending`，不会出现在大屏，后台可审核。
- 幂等重复提交返回 `200`，并带 `"duplicate": true`。

## 3. 后台接口

### 3.1 登录

`POST /api/admin/login`

```json
{ "password": "admin123" }
```

成功：`200`，`Set-Cookie: sw_session=...`

```json
{ "ok": true, "data": { "mustChange": true } }
```

失败：`401 BAD_PASSWORD`；`429 RATE_LIMITED`。

### 3.2 退出登录

`POST /api/admin/logout` → 清除 Cookie。

### 3.3 当前会话

`GET /api/admin/session`

```json
{ "ok": true, "data": { "role": "admin", "mustChange": false, "expiresAt": 1792783200000 } }
```

### 3.5 更新活动配置

`POST /api/admin/config`（需要 CSRF 头）

可只提交需要修改的字段，服务端做白名单与范围校验：

```json
{
  "event": { "title": "云栖山 · 山水留痕", "subtitle": "落笔成景", "org": "云栖山风景区", "venue": "游客中心", "date": "2026-10-23" },
  "theme": { "preset": "dawn", "accent": "#e8a869", "paper": "#f6f1e6" },
  "wall": { "mode": "star", "maxItems": 60, "standbySeconds": 45, "showQr": true, "showTicker": true, "sound": true, "photoWall": true },
  "kiosk": { "camera": true, "print": true, "allowMessage": true },
  "moderation": { "autoApprove": true, "action": "mask", "maxName": 16, "maxMessage": 80 },
  "mobileUrl": "https://wall.example.com/mobile"
}
```

约束：

- `theme.preset` ∈ `ink | dawn | night`
- `theme.accent / paper` 必须为 `#RRGGBB`
- `wall.mode` ∈ `globe | star | bubble`
- `wall.maxItems` 8–200，`standbySeconds` 10–600
- `moderation.action` ∈ `mask | reject`
- `moderation.maxName` 2–32，`maxMessage` 10–200
- `mobileUrl` 必须以 `http://` 或 `https://` 开头；可填域名根地址（如 `https://wall.example.com`），服务端会自动规范化为 `https://wall.example.com/mobile`；填空字符串表示恢复自动识别
- 配置 `mobileUrl` 后，`/api/config` 的 `mobileUrl` 与 `publicBaseUrl` 均以此为准，大屏二维码、海报二维码、后台「其他设备访问」二维码同步切换，因此可用于公网域名 / 内网穿透部署

返回完整公开配置；同时通过 WebSocket 广播 `config:update`。

### 3.6 修改管理员口令

`POST /api/admin/password`（需要 CSRF 头）

```json
{ "current": "admin123", "next": "new-password-888" }
```

- `400 BAD_PASSWORD`：当前口令错误
- `400 WEAK_PASSWORD`：新口令少于 8 位
- 成功后会重新下发会话 Cookie

### 3.7 敏感词管理

`POST /api/admin/words`（需要 CSRF 头）

```json
{ "add": ["代开发票", "加微信"], "remove": ["sb"] }
```

```json
{ "ok": true, "data": { "added": ["代开发票"], "removed": ["sb"], "words": ["..."] } }
```

单次最多 200 个；重复词会被忽略。

### 3.8 签名审核 / 删除

`POST /api/admin/signatures/:id`（需要 CSRF 头）

```json
{ "action": "approve" }
```

| action | 效果 |
| --- | --- |
| `approve` | 通过 → `approved`，广播 `signature:new`，立即上墙 |
| `hide` | 隐藏 → `hidden`，广播 `signature:remove`，大屏移除 |
| `pending` | 退回待审核 |
| `delete` | 删除数据与媒体文件，广播 `signature:remove` |

### 3.9 一键清屏

`POST /api/admin/wall/clear`（需要 CSRF 头）

```json
{ "confirm": "CLEAR", "keepMedia": false }
```

```json
{ "ok": true, "data": { "count": 128, "backup": "before-clear-1792740000000.json" } }
```

清空前自动备份到 `data/exports/`，并广播 `wall:clear`。累计计数不清零。

### 3.10 数据导出

`GET /api/admin/export?format=csv|json`

- `csv`：`text/csv; charset=utf-8`，带 UTF-8 BOM，单元格已转义并防公式注入
- `json`：完整配置、词库、统计、签名（不含任何口令字段）
- 均以附件形式下载：`Content-Disposition: attachment; filename="signatures-<时间>.csv"`

### 3.11 系统状态

`GET /api/admin/system` → 与 `overview.system` 相同。

### 3.12 网络诊断（二维码地址）

`GET /api/network`

返回可用于二维码的地址列表（按"手机可达性"排序）、当前生效地址与手动配置值。

```json
{
  "ok": true,
  "data": {
    "port": 8080,
    "host": "localhost",
    "configured": null,
    "effective": "http://10.206.118.146:8080/mobile",
    "recommended": "http://10.206.118.146:8080/mobile",
    "candidates": [
      {
        "name": "WLAN",
        "address": "10.206.118.146",
        "netmask": "255.255.255.0",
        "virtual": false,
        "score": 48,
        "mobileUrl": "http://10.206.118.146:8080/mobile",
        "origin": "http://10.206.118.146:8080"
      },
      {
        "name": "VMware Network Adapter VMnet1",
        "address": "192.168.189.1",
        "netmask": "255.255.255.0",
        "virtual": true,
        "score": -80,
        "mobileUrl": "http://192.168.189.1:8080/mobile",
```

- `virtual: true` 表示 VMware / Hyper-V / VirtualBox / Docker / WSL 等虚拟网卡，手机通常不可达。

- 后台「活动配置 → 对外访问地址」下拉框即由该接口填充；手动保存后 `configured` 与 `effective` 相同。

## 4. WebSocket

### 4.1 连接

```
ws://<host>:8080/ws?role=wall
```

- 仅支持路径 `/ws` 与 `Sec-WebSocket-Version: 13`
- 客户端帧必须掩码；服务端支持文本帧、分片、Ping/Pong
- 单帧上限 64 KB（大图请走 HTTP）
- 连接建立后服务端立即下发 `hello`

### 4.2 角色

连接后发送：

```json
{ "type": "hello", "role": "wall" }
```

`role` ∈ `wall`（大屏）/ `mobile`（手机）/ `admin`（后台）。角色用于过滤推送。

### 4.3 服务端 → 客户端事件

| type | 触发 | 载荷 |
| --- | --- | --- |
| `hello` | 连接建立 | `{ serverTime, config, stats, items }` |
| `signature:new` | 新签名通过 / 审核通过 | `{ item, stats }` |
| `signature:pending` | 新签名待审核（仅 admin 角色） | `{ item, stats }` |
| `signature:remove` | 隐藏 / 删除 | `{ id, stats }` |
| `wall:clear` | 一键清屏 | `{ count, stats }` |
| `config:update` | 后台保存配置 | `{ config }` |
| `stats` | 每 15 秒 | `{ stats, serverTime }` |
| `pong` | 回应客户端 ping | `{ t }` |

`hello` 示例：

```json
{
  "type": "hello",
  "serverTime": 1792740000000,
  "config": { "event": { }, "theme": { }, "wall": { } },
  "stats": { "total": 128, "today": 96, "approved": 128, "pending": 0, "photos": 12, "messages": 64, "words": 41 },
  "items": [ ]
}
```

### 4.4 客户端 → 服务端事件

| type | 载荷 | 说明 |
| --- | --- | --- |
| `hello` | `{ role }` | 声明角色 |
| `ping` | `{ t }` | 心跳，服务端回 `pong` |

### 4.5 心跳与重连

- 服务端每 25 秒发送 Ping；70 秒无任何消息则断开该连接。
- 客户端每 20 秒 `ping`；3.5 个周期无消息主动重连。
- 重连使用指数退避（400ms 起，上限 15s，带 ±30% 抖动），恢复后重新收到 `hello` 全量快照。

### 4.6 自建客户端示例

```js
const ws = new WebSocket('ws://192.168.1.20:8080/ws?role=wall');
ws.onopen = () => ws.send(JSON.stringify({ type: 'hello', role: 'wall' }));
ws.onmessage = (ev) => {
  const msg = JSON.parse(ev.data);
  if (msg.type === 'signature:new') console.log('新签名', msg.item.name, msg.item.signatureUrl);
};
```

```json
{
  "id": "sig_mvkspnju_02ee2d8e",
  "name": "林见山",
  "message": "山水有相逢",
  "signatureUrl": "/media/sig_mvkspnju_02ee2d8e-signature.png",
```

| 字段 | 说明 |
| --- | --- |

| `today` | 今日提交数 |
| `approved` / `pending` / `hidden` | 当前各状态数量 |
| `photos` / `messages` | 含留影 / 含留言数量 |
| `words` | 敏感词数量 |
| `stored` | 当前存储条数（后台） |
| `media` | `{ count, bytes }` 媒体统计（后台） |

## 6. 错误码

| code | HTTP | 含义 | 处理建议 |
| --- | --- | --- | --- |
| `SIGNATURE_REQUIRED` | 400 | 缺少签名图片 | 提示用户先书写 |
| `BAD_IMAGE` | 400 | 图片格式非法 | 重新导出 PNG/JPEG |
| `IMAGE_TOO_LARGE` | 413 | 图片超限 | 压缩后重试 |
| `BAD_SIGNATURE` | 400 | 签名不是透明 PNG | 检查导出逻辑 |
| `TEXT_REJECTED` | 422 | 命中敏感词且策略为拒收 | 返回 `detail.hits` 给用户修改 |
| `BODY_TOO_LARGE` | 413 | 请求体超过 12MB | 缩小图片 |
| `BAD_JSON` | 400 | 请求体不是合法 JSON | 检查 Content-Type 与序列化 |
| `NOT_FOUND` | 404 | 资源 / 接口不存在 | — |
| `METHOD_NOT_ALLOWED` | 405 | 方法不支持 | — |
| `UNAUTHORIZED` | 401 | 未登录或会话过期 | 重新登录 |
| `BAD_PASSWORD` | 400/401 | 口令错误 | 重试 / 重置 |
| `WEAK_PASSWORD` | 400 | 新口令少于 8 位 | 换更长口令 |
| `CSRF_CHECK_FAILED` | 403 | 缺少 `X-Requested-With` | 按文档补齐请求头 |
| `CONFIRM_REQUIRED` | 400 | 清屏未输入 CLEAR | 二次确认 |
| `BAD_ACTION` | 400 | 未知审核动作 | 使用 approve/hide/pending/delete |
| `RATE_LIMITED` | 429 | 触发限流 | 读取 `Retry-After` 后重试 |
| `INTERNAL` | 500 | 服务端异常 | 查看 `data/logs` |

## 7. 调用示例

### cURL

```bash
# 提交签名
curl -X POST http://127.0.0.1:8080/api/signatures \
  -H "Content-Type: application/json" \
  -d '{"name":"测试","signature":"data:image/png;base64,iVBORw0KGgo..."}'

# 登录并保存 Cookie
curl -c cookie.txt -X POST http://127.0.0.1:8080/api/admin/login \
  -H "Content-Type: application/json" -d '{"password":"admin123"}'

# 导出 CSV
curl -b cookie.txt "http://127.0.0.1:8080/api/admin/export?format=csv" -o signatures.csv
```

### PowerShell

```powershell
$body = @{ name = "测试"; signature = "data:image/png;base64,..." } | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:8080/api/signatures -Method Post -ContentType 'application/json' -Body $body

$s = New-Object Microsoft.PowerShell.Commands.WebRequestSession
Invoke-RestMethod -Uri http://127.0.0.1:8080/api/admin/login -Method Post -WebSession $s `
  -ContentType 'application/json' -Body '{"password":"admin123"}'
Invoke-RestMethod -Uri http://127.0.0.1:8080/api/admin/overview -WebSession $s
```

### 前端

```js
const res = await fetch('/api/signatures', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: '测试', signature, clientToken: 'tk_1' }),
});
const { ok, data, error } = await res.json();
```
