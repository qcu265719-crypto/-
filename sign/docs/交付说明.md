# 交付说明（甲方版）

> 项目：山水留痕 · 电子签名墙 v1.0.0
> 本包为**免安装绿色版**：已内置 Node.js 运行环境，双击即可运行，无需安装数据库、无需联网。

---

## 一、包内有什么

| 文件/目录 | 说明 |
| --- | --- |
| `启动签名墙.bat` | **每天用它启动服务**（黑窗口保持开着） |
| `打开大屏.bat` | 一键全屏打开大屏（Chrome / Edge） |
| `打开管理后台.bat` | 一键打开管理后台，并自动复制局域网后台地址到剪贴板 |
| `启动公网访问.bat` | 一键建立 Cloudflare 临时隧道，手机用 4G / 异地也能扫码（需现场能上外网） |

| `runtime\node.exe` | 内置 Node.js 运行时，无需另行安装 |
| `tools\cloudflared.exe` | 内网穿透客户端（公网访问用，Cloudflare 官方程序） |

## 二、方式一：现场单机使用（推荐）

适用于景区游客中心、展位、婚礼现场等**一台触摸屏 + 多台手机**的场景。

### 1. 启动

双击 **`启动签名墙.bat`**，出现黑色窗口并显示：

```
大屏展示   http://localhost:8080/
手机签名   http://192.168.x.x:8080/mobile
管理后台   http://localhost:8080/admin
二维码地址 192.168.x.x（Wi-Fi 网卡名）
```

- **黑窗口不要关**，关掉即停止服务。
- 首次运行会自动初始化，管理员口令为 `admin123`。
- 若 Windows 弹出防火墙提示，请勾选"专用网络"并允许；或直接运行 `开放防火墙端口.bat`。

### 2. 打开大屏

双击 **`打开大屏.bat`**，自动全屏打开签名墙。

- 退出全屏：`Alt + F4`。
- 也可手动用 Chrome 打开 `http://localhost:8080/`，按 `F` 切换全屏。

### 3. 手机签名

1. 手机连接与大屏电脑**同一个 Wi-Fi**。
2. 扫描大屏右下角二维码。
3. 手写 → 下一步 →（可选拍照）→ 留言 → 生成海报 → 提交上墙。

> 二维码下方会显示对外访问地址，可先在手机浏览器里直接输入核对该地址是否可达。

### 4. 后台管理

浏览器打开 `http://localhost:8080/admin`（或双击 `打开管理后台.bat`），默认口令 `admin123`。

首次使用请按顺序完成：

1. 「系统状态 → 修改管理员口令」；
2. 「活动配置」填写活动标题、主办方、场地、日期，选择主题与签名墙形态；
3. 「签名墙」「敏感词」按需调整；
4. 交付包 `data` 为空，无需清屏；若使用演示数据再执行「一键清屏」。

### 5. 其他设备打开后台

手机、平板、其他电脑**不需要安装任何程序**，只要与服务器在同一局域网：

- 直接访问 `http://<服务器IP>:8080/admin`；
- 或在大屏/后台左侧点「其他设备访问 ↗」，用手机扫二维码直接打开；
- 后台登录仍需管理员口令。

`打开管理后台.bat` 会自动识别本机局域网地址、复制到剪贴板并打开浏览器。如果要在**另一台 Windows 电脑**上用它连接服务器，可带参数运行：

```bat
打开管理后台.bat 10.206.118.146 8080
打开管理后台.bat http://wall.example.com
```

> 其他设备打不开后台时，与手机扫码打不开的处理相同：同一 Wi-Fi、放行防火墙、避开虚拟网卡地址。

## 三、方式二：甲方内网服务器 / 多终端使用

适合景区有多块屏、多台工作电脑、需要长期运行的场景。

1. 把整个文件夹放到一台**常开的内网服务器 / 工控机**（Windows 10/11 或 Windows Server）。
2. 在该机器上双击 `启动签名墙.bat`，保持运行；建议设置开机自启（把快捷方式放进 `shell:startup`）。
3. 其他设备（大屏、平板、办公电脑）访问：
   - 大屏：`http://<服务器IP>:8080/`
   - 后台：`http://<服务器IP>:8080/admin`
   - 手机：扫大屏二维码，或 `http://<服务器IP>:8080/mobile`
4. 手机与大屏必须在同一内网；服务器 IP 建议在路由器做 **DHCP 保留**，避免地址变化导致二维码失效。

> 多块大屏同时打开 `http://<服务器IP>:8080/` 会实时同步，可做"主屏 + 副屏"。

## 四、方式三：公网访问（跨网络 / 异地）

默认的局域网地址**出了这个网络就打不开**（例如手机用 4G、甲方在办公室）。要让二维码和后台在任何网络都能打开，必须提供一个公网入口。本包附带 `deploy/` 部署套件与详细说明：

```
deploy/
├─ README.md                 三种跨网络方案：公网服务器 / 内网穿透隧道 / 端口映射
├─ nginx.conf                Nginx 反向代理（含 HTTPS 与 WebSocket）
└─ signature-wall.service    Linux systemd 常驻配置
```

### 最快：一键公网（本包已内置隧道客户端）

1. 双击 `启动签名墙.bat`，等它显示地址；
2. 双击 **`启动公网访问.bat`**；
3. 约 5–20 秒后窗口会显示公网地址并自动复制，例如：
   `https://xxx-xxx-xxx.trycloudflare.com`
4. 程序会自动把它写入后台「对外访问地址」，大屏二维码、海报二维码、后台二维码立即变成公网地址；
5. 手机用 4G、甲方在异地，扫码即可使用；后台访问 `https://该地址/admin`；
6. **关闭窗口或按 Ctrl+C**：断开隧道，并自动恢复原来的局域网设置。

前提：现场电脑能访问外网（能打开网页），且网络未封禁 Cloudflare。

> 若直接关闭窗口（而不是按 Ctrl+C），隧道会断开，但后台可能残留旧地址（访问会显示 530）。本版服务端会自动探测：连续失败后约 2–3 分钟恢复局域网地址；也可在后台把「对外访问地址」清空立即恢复。重新双击 `启动公网访问.bat` 会生成新地址并自动写回。

> 这是 Cloudflare 的**免费临时隧道**：地址每次重启都会变化、没有可用性承诺，适合演示与临时活动；正式活动请用固定域名（下方"推荐"方案）。

### 推荐：公网服务器 + 域名 + HTTPS

1. 准备一台有公网 IP 的服务器与一个域名（解析到服务器）；
2. 按 `deploy/README.md` 安装 Node.js、部署程序、配置 systemd 与 Nginx；
3. 申请 HTTPS 证书（certbot 一条命令）；
4. 后台「活动配置 → 对外访问地址」填 `https://你的域名`（保存时自动补 `/mobile`）。

设置后：

- 大屏二维码、海报二维码 → `https://你的域名/mobile`；
- 后台「其他设备访问」二维码 → `https://你的域名/admin`；
- 手机用 4G / 甲方在任何网络都能扫码使用，数据仍实时同步。

### 临时方案：内网穿透（无需公网服务器）

现场电脑保持联网，运行 Cloudflare Tunnel / ngrok / frp 等隧道客户端，得到一个公网 HTTPS 地址（如 `https://xxx.trycloudflare.com`），然后：

1. 后台「活动配置 → 对外访问地址」填该地址；
2. 保存后二维码与后台地址自动切换；
3. 注意免费隧道**重启后地址会变**，需重新填写；正式活动建议用固定域名。

> 隧道/公网部署需现场网络能够访问外网；本项目运行时不依赖外网，但"跨网络访问"这一需求本身必须由公网入口满足。详细命令与注意事项见 `deploy/README.md`。

注意事项：

- 公网必须使用 **HTTPS**，否则手机网页相机被浏览器禁用（可用"从相册选择"兜底）；
- 后台口令务必改为强口令，并尽量限制后台访问来源（Nginx 可按 IP 限制）；
- 公网部署涉及备案、证书、安全加固，建议由甲方 IT 或我方另行实施。

## 六、数据、备份与清屏

- 所有数据都在 `data\` 目录：`db.json`（配置与签名记录）、`media\`（签名图与留影）、`exports\`（导出与清屏备份）、`logs\`（日志）。
- **备份**：直接复制整个 `data\` 文件夹到 U 盘或移动硬盘。
- **清屏**：后台「一键清屏」（需输入 CLEAR），会先自动备份再清空；累计计数保留。
- **迁移**：复制整个程序目录与 `data\` 到新电脑即可，无需重新配置。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击启动提示"未检测到 Node.js" | 确认 `runtime\node.exe` 存在；或安装 Node.js 18+ |
| 浏览器打不开 | 黑窗口是否开着；`http://localhost:8080/healthz` 是否返回 JSON；端口被占用可改 `set PORT=8081` 后重启 |
| 手机扫码打不开 | 同一 Wi-Fi？后台「活动配置 → 对外访问地址」选 WLAN（不要选标"虚拟网卡"的）→ `开放防火墙端口.bat` → 检查路由器 AP 隔离 |
| 手机用 4G / 异地打不开 | 局域网地址无法跨网络，需公网入口：按 `deploy/README.md` 部署公网服务器或内网穿透，并在后台「对外访问地址」填公网域名 |
| 手机相机打不开 | 局域网 HTTP 下浏览器限制，改用"从相册选择"；或部署 HTTPS |
| 打印没反应 | 浏览器拦截弹窗，允许本站弹窗；打印时勾选"背景图形" |
| 想换端口 | 命令行 `set PORT=8090` 后运行，或修改 bat 中的启动命令 |

## 八、系统要求与安全

- Windows 10/11（或 Windows Server 2016+），4 GB 内存以上；
- 大屏浏览器：Chrome / Edge 100+；
- 手机：iOS Safari 15+ / Android Chrome / 微信内置浏览器；
- 首次登录后**必须修改管理员口令**；后台不要暴露到公网；
- 活动期间关闭系统休眠、屏保与自动更新。
